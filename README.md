## Files
- `index.html` – the complete website (HTML + CSS + JavaScript in one file, no build step).
- `README.md` – this file.

## Edit your details
Open `index.html`, scroll to the bottom and edit the `CONFIG` block:
- `email`, `phone`, `whatsapp`, `linkedin`
- `github` – your GitHub profile (the GitHub contact link stays hidden while empty)
- `githubRepos` – links for FlowPay, FemHealth, ShopEase (each "View source" button stays hidden while empty)
